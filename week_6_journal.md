### Meeting with VK Wednesday, October 21st
As a team, we met up with VK in person and showed them Michael's prototype to begin with, to see if we were on the right track, since they were enjoying it more, but still hesitating about colour and space, we ended up showing Mars' variations as well.

Here is what VK gave us as directions:
+ Potentially having content organized into groups inside each season.
+ Likes the framing vignette, but wants it to blend more into the background.
+ Still wants the website to be completely white.
+ Wants there to be tension between clinical and natural and have that contrast be aparent in teh website through images.
+ Wants to draw more for the website and potentialy have scans of oil on paper but while it is still wet.
+ There is a picture of a bird that was taken multiple times from January to spring, so because that image is important and tells a story, we need to organize the images so that it does not start off the story too strong, but also keeps a flow of events.
+ Still really likes the navigation bar.
+ Scrolling through the website flows into images of the waterfall.
+ Start the website out with images of the hospital and more uncolourful and clinical images, then have it flow into nature and its changes throughout the seasons.
+ Bits of sound interjected while scrolling through the website (perhaps when an image is clicked on) to give it more context.
+ Having more clickable and interactible features (perhaps being able to click enter at the start and it flows the user into the website like a stream).
+ Enjoyed the gallery prototype look because of its spacing.
+ Likes the zoom in and out of images, but wants the zoom out to show all the images on the page.
+ Wants thin ink lines.
+ Perhaps if the user does not touch the page for a couple minutes, the website will scroll automatically.
